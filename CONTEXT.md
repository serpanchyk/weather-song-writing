# Weather Song Writing

This context describes the product language for a demo that generates weather-inspired lyrics and compares model outputs.

## Language

**User**:
A person using the demo to generate weather-inspired lyrics and inspect the model comparison result.
_Avoid_: Reviewer, evaluator

**Lyrics**:
Text generated from weather conditions, written in a song-like structure without implying audio, melody, or musical arrangement.
_Avoid_: Song, track, composition

**Candidate Output**:
One set of lyrics generated by a selected model for the same weather input, considered anonymously during evaluation.
_Avoid_: Candidate, generation, model output

**Selected Model**:
An OpenRouter model chosen by the user to produce a candidate output for the same weather input.
_Avoid_: Candidate model, option, LLM

**Weather Input**:
The shared location, time, and resolved weather conditions used to generate the same prompt for every selected model.
_Avoid_: Weather prompt, prompt context, request data

**Weather Moment**:
A user-selected city and local date/time used to resolve weather conditions for the lyrics prompt.
_Avoid_: Location/time, timestamp, coordinates
